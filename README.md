# FloodWatch Gambia

The tracked React application is in [frontend/frontend/](frontend/frontend/README.md). It integrates accessible reporting, a community map, saved report references, safety guidance, help requests and a protected authority workspace with the REST API in [backend/](backend/README.md).

Start the backend on port 5000, then run `npm run dev` in `frontend/frontend/`. See the [integration audit](INTEGRATION.md) for all endpoints, request mappings, fixes and verification limits. The separate nested `Floodwatch-gambia/` repository copy is not used by this application.
